# 표시·광고 명시사항 체크리스트 (매물 올리기 전 필수)

근거: 공인중개사법 제18조의2, 시행령 제17조의2,
「중개대상물의 표시·광고 명시사항 세부기준」(국토교통부고시 제2024-748호, 2025.1.1 시행)
최종 확인: 2026-11-26 (고시 개정 여부는 작업 때마다 재확인)

## 1. 중개사무소 정보 (모든 페이지)
- 명칭 / 소재지(등록증 기준) / 연락처 / 등록번호 / 개업공인중개사 성명
- 사이트 하단 footer에 자동 표시됨 → build.py 수정 시 빠지지 않게 확인

## 2. 건축물 명시사항 (상세 이미지 '매물정보' 표)
| 항목 | 기준 |
|---|---|
| 소재지 | 건축물대장 기준. 단독주택(별표1 제1호 가목) = 지번 포함(의뢰인 원치 않으면 동까지 가능). **다가구·다중주택 등 그 외 주택 = 지번 필수(예외 없음)**. 주택 외 건축물 = 동까지 가능 + 층수 포함 |
| 면적 | ㎡ 표기. 전용면적(일반건축물대장은 현황면적). 대지/토지면적 병기 가능, 토지면적은 토지대장 기준 |
| 가격 | 단일가격 (매매가) |
| 종류 | 건축물대장 용도 (예: 제2종근린생활시설) |
| 거래형태 | 매매 / 임대 등 |
| 총 층수 | 건축물대장 기준 |
| 사용승인일 | 건축물대장 기준 |
| 방향 | 주택 = 안방·거실 등 주실 기준 / 그 외 = 주된 출입구 기준, **기준을 함께 표시** |
| 방 수·욕실(화장실) 수 | **화장실 수는 근생도 필수**. 주택(준주택 포함)이 아니면 방 수만 생략 가능 |
| 입주가능일 | **세부 날짜 / '즉시입주' / ○월 초·중·하순 중 하나만 허용**. '협의', '승계'만 쓰면 안 됨 → 예: 즉시입주(승계) |
| 주차대수 | 총 주차대수 |
| 관리비 | 주택 외 건축물은 생략 가능. 주택은 표시(통건물은 '해당 없음' + 사유) |
| 위반건축물 | 대장에 위반 기재 시 "위반건축물" 표시 |

## 3. 토지
- 소재지(동까지 가능) / 면적(토지대장, ㎡) / 가격 / 지목 / 거래형태

## 4. 부당 표시·광고 주의
- 수익 보장 오인 표현 금지: '확정', '보장' 등 → '현 계약 임대료', '매도인 제시 기준'
- 수익률은 산식·기준(매도인 제시 임대현황 등) 함께 표기
- 영업·사업체가 매매에 포함된 것처럼 읽히는 표현 금지
- 역까지 거리 등 수치는 근거(네이버 지도 등) 있는 값만
- **거래 완료 매물은 즉시 삭제** (미삭제 시 과태료 최대 500만 원)
